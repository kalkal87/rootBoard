# Findings: Jobs to Be Done

## Framework
- **Name:** Jobs to Be Done
- **Slug:** jobs-to-be-done
- **Lens summary:** Identifies the underlying job a customer is "hiring"
  the product to do, and where the product currently fails to do that job.

## Observations
- The onboarding flow changed in the same window signups went flat
  (founder note, line 2).
- A few users churned after week 2, saying something like "didn't really
  need it after trying it out" (founder note, line 4).

## Assumptions
- Assuming the "few" churned users' comment reflects a broader pattern
  rather than two or three isolated cases — the input gives one paraphrased
  quote, not a count or a trend.

## Open Questions
- How many users does "a few" represent, out of how many total signups?
  Without a denominator this can't be sized.
- Did the onboarding change happen before or after the churn comments
  started, or in the same window as the signup flatness? The input doesn't
  establish sequencing.

## Problems Identified

### Problem 1: Users may be completing onboarding without finding the job they came for
- **Problem Statement:** Some users appear to try the product, complete
  onboarding, and conclude they don't have the job this product does —
  "didn't really need it after trying it out" — which would make this a
  retention/fit problem downstream of signup, not an acquisition problem.
  The input gives one paraphrased comment to go on, not a pattern.
- **Impact / Symptoms:** A few users churned after week two, coinciding with
  the onboarding change, though the sequence remains unclear.
- **Proof Points:**
  - "A few users churned after week 2, said something like 'didn't really
    need it after trying it out.'" (founder note, line 4)
- **Confidence:** Low

## Coverage Note
Jobs to Be Done technically applies — there's a hint of an unmet-job
signal — but the evidence is a single paraphrased comment from "a few"
unspecified users, not a source this framework can confidently reason from.
This finding should be treated as a lead worth investigating, not a
conclusion.
